# IEEE 802.3 Standards

The IEEE 802.3 standard family defines the technical specifications for Ethernet. These standards dictate how data frames are transmitted across physical media, ensuring interoperability between hardware from different manufacturers. The 802.3 standards are highly granular, they establish specific requirements for varying data transfer speeds, the type of cabling used (such as copper or fiber), and the maximum reliable transmission distance.

When planning network infrastructure, engineers must select the appropriate 802.3 standard to match the requirements of the environment. Choosing the correct standard ensures that the signal remains strong and reliable across the entire length of the cable run. If a cable run exceeds the maximum distance specified by the standard, signal degradation will occur, leading to data loss and connectivity issues.

The following table summarizes common Ethernet standards widely utilized in local area networks:

| Standard | Speed | Informal Name | Max Length |
| :--- | :--- | :--- | :--- |
| **10BASE-T** | 10 Mbps | Ethernet | 100 meters |
| **100BASE-TX** | 100 Mbps | Fast Ethernet | 100 meters |
| **1000BASE-T** | 1 Gbps | Gigabit Ethernet | 100 meters |
| **10GBASE-T** | 10 Gbps | 10-Gigabit Ethernet | 100 meters |
