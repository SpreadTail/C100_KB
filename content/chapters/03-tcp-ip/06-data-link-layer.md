# Layer 2: Data Link

The **Data Link layer** is responsible for the reliable delivery of data between two nodes that are physically connected to the same network segment. While the Physical layer is concerned with the transmission of raw bits, the Data Link layer organizes these bits into structured units called frames. It provides the necessary controls to ensure that data is successfully prepared for transmission and that the hardware on the receiving end can interpret the incoming information correctly.

In network architecture, the movement of data from one device to the next directly connected device is known as a **hop**. Data typically does not travel from the final source to the final destination in a single, unbroken line. Instead, it must traverse a series of intermediate nodes—such as switches and routers—to reach its destination. The Data Link layer manages the traffic across each of these individual hops, ensuring the data is transferred safely from one node to the next before it continues its journey across the network.

To facilitate this process, the layer utilizes **Media Access Control (MAC)** addresses. A MAC address is a unique, permanent identifier assigned to every network interface controller (NIC) by the manufacturer. Unlike logical addresses, which are assigned based on the network configuration, the MAC address acts as a physical label. When data is transmitted at this layer, it is encapsulated in a frame that includes the destination MAC address. This allows the networking hardware, such as a switch, to identify exactly which physical device on the local network should receive the data, ensuring the information arrives at the intended destination on the current hop.
