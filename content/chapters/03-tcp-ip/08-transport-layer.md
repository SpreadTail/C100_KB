# Layer 4: Transport

The **Transport layer** is responsible for process-to-process communication. While the Network layer is concerned with delivering data to the correct host, the Transport layer provides the necessary logic to ensure that data is delivered to the correct application running on that host. This distinction is critical in modern computing, as a single computer often runs multiple networked applications simultaneously—such as a web browser, an email client, and a streaming application. The Transport layer manages these disparate data streams, ensuring each one reaches the appropriate software process without interference.

To achieve this granular level of delivery, the Transport layer utilizes the concept of **ports**. A port is a logical endpoint for a specific communication channel. Each application on a host is assigned a unique port number; for example, web traffic commonly uses port 80 or 443, while email traffic uses distinct, standardized ports. When data arrives at a destination host, the operating system inspects the port number attached to the data packet. It then forwards that packet to the specific application associated with that port.

By identifying the destination not just by the computer (the IP address), but by the specific application (the port number), the Transport layer enables seamless multitasking. It organizes the data into segments, manages flow control to prevent the receiver from being overwhelmed, and ensures that the communication between the source process and the destination process is handled reliably.
