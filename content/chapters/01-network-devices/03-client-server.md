# Clients and Servers

Within a computer network, devices interact with one another by taking on specific operational roles. The two most fundamental roles in network communication are clients and servers. These terms describe the relationship and direction of communication between two nodes when they exchange data or share resources.

## Client

A **client** is a device that requests and accesses a service or resource provided by another device on the network. When a computer opens a web browser to load a webpage, or uses an application to check for new emails, it is acting as a client. The client initiates the communication by sending a request out into the network.

## Server

A **server** is a device that listens for incoming requests and provides the corresponding services or data back to the clients. A server's primary function is to host and distribute resources. Common examples include file servers that hold shared documents, web servers that deliver website data, and print servers that manage incoming print jobs from multiple computers.

> It is important to understand that client and server describe behavioral roles rather than specific types of hardware. These roles can be assumed by a wide variety of devices. Depending on the exact context of the communication, almost any node can function as a client, a server, or both simultaneously. For example, a standard desktop computer acts as a client when it downloads a file from a website, but it acts as a server if it shares a folder of its own files with another laptop on the same local network.
